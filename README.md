### projects i built that made my life easier.

- [piwa](https://github.com/PTBYSR/piwa) — built a bridge to interact with my system using an AI agent (Pi) via WhatsApp, wanted to vibe code without needing a laptop with me.
- [render-alive](https://render-alive-seven.vercel.app/) — didn't want to pay $7/month for web services on Render, so fixed the 15-minute downtime on the free tier. ( currently 8 active users ).
- [oldy](https://github.com/PTBYSR/oldy) — had an old laptop lying around, so decided to host local LLMs on it and make it accessible via an API.
- [anti-provider](https://github.com/PTBYSR/anti-provider) — took advantage of free use of Opus on Antigravity by building a zero-dependency OpenAI-compatible proxy bridge.
- [pentestkit](https://github.com/PTBYSR/pentestkit) — was looking for a sandboxed environment where my AI agent could run security tests without host guardrails.
